Does knowing the CARS model change how authors write?

How this works. You will read 4 introductions from published research articles — all written by the articles' human authors, none AI-generated, one per journal quartile (Q1…Q4). Each comes from an article that itself engages with Swales' CARS model or rhetorical move analysis somewhere — a note above each text says exactly where that engagement appears (sometimes inside the introduction shown here, sometimes elsewhere in the paper). The question we want your view on: does familiarity with the CARS framework show in how the authors structure their own introduction? The colored highlights are the rhetorical moves as identified by an automatic annotator, the same system for every text — treat them as an imperfect aid. Write a comment for each paper. Comments save automatically in this browser; when you are done (or as a backup), press Download comments and send the file to the research team. Please use the same browser on the same computer throughout, not in private/incognito mode. All texts are shown as a single continuous paragraph on purpose; minor formatting glitches come from PDF text extraction and are not meaningful.
