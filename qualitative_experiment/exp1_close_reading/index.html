Close reading — human vs AI introductions

How this works. There are papers. For each paper you will read three versions of its introduction, shown one after another: the original written by the article's authors, and two versions generated by a large language model that was given the article's content and cited works but not its introduction — one from a basic prompt (just “write the introduction”) and one from a CARS-guided prompt (the model was additionally given Swales' CARS move scheme and asked to plan its rhetorical moves first). All three carry colored move annotations produced by the same automatic annotator. Read the three versions, then write your observations in the comment box at the bottom — there are no fixed questions; comparisons, oddities, and single striking details are all welcome. Comments save automatically in this browser; when you are done (or as a backup), press Download comments and send the file to the research team. Please use the same browser on the same computer throughout, and don't use private/incognito mode.
